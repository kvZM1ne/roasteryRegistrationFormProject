# Roastery. — Coffee Subscription Registration Form

## English

A two-column registration form for a monthly specialty coffee bean subscription service. Built as a frontend practice project using semantic HTML5, BEM methodology, and responsive Flexbox layout.

### Features
- Two-column card layout with a split visual and form section
- Custom-styled radio buttons for gender and subscription weight selection (250g, 500g, 1kg)
- Basic form validation and terms agreement checkbox
- Responsive design for desktop and mobile screens

### Technologies
- HTML5
- CSS3 (Flexbox, CSS Custom Properties, Media Queries)
- Google Fonts (Lora & Inter)

## Беларуская

Двухкалонкавая форма рэгістрацыі для сэрвісу штомесячнай падпіскі на зернавую каву. Праект выкананы як практычнае заданне па вёрстцы з выкарыстаннем семантычнага HTML5, метадалогіі БЭМ і адаптыўнай сеткі на Flexbox.

### Асаблівасці
- Двухкалонкавая картка з візуальнай часткай і анкетай
- Кастомныя радыёкнопкі для выбару полу і аб'ёму падпіскі (250g, 500g, 1kg)
- Базавая валідацыя палёў і чэкбокс згоды з умовамі
- Адаптыўнасць пад дэсктопныя і мабільныя экраны

### Тэхналогіі
- HTML5
- CSS3 (Flexbox, Media Queries)
- Google Fonts (Lora & Inter)
